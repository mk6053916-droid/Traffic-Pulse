Congestion Levels & Operational Thresholds

How TrafficPulse defines and differentiates traffic states using vehicle density and free-flow velocity ratios.

Class 0 Free-Flowing

Low Congestion

Traffic moves at or near posted speed limits with minimal queueing.

  • Observed Speed: > 70% of road design speed
  • Vehicle Volume: Light (< 30% corridor capacity)
  • Commute Impact: Negligible delay; optimal travel window
Class 1 Medium Density

Moderate Congestion

Stable flow with minor braking near intersections and commercial access points.

  • Observed Speed: 40% – 70% of road design speed
  • Vehicle Volume: Moderate (30% – 70% capacity)
  • Commute Impact: 2 to 6 minute signal wait; safe spacing advised
Class 2 Heavy / Bottleneck

High Congestion

Stop-and-go conditions, junction spillover, and severe speed degradation.

  • Observed Speed: < 40% of road design speed
  • Vehicle Volume: Saturated (> 70% capacity)
  • Commute Impact: Significant delays; alternate routes recommended

Model Architecture

Machine Learning Pipeline Flow

How user inputs transform into normalized vectors and probability predictions through Scikit-learn.

Step 1

Feature Ingestion

Captures 5 parameters: Road Corridor, Day of Week, Hour (0–23), Vehicle Count, and Average Speed.

Raw Dict / JSON
Step 2

One-Hot Encoding

Converts nominal roads (5) and days (7) into binary indicators; combines with 3 numerical values.

15-D NumPy Vector
Step 3

StandardScaler

Normalizes features via z = (x - μ) / σ so large counts don't dominate speed.

Zero Mean, Unit Var
Step 4

Softmax Decision

Logistic Regression evaluates class scores and computes 3 calibrated class probabilities summing to 1.0.

Argmax Class (0, 1, 2)
