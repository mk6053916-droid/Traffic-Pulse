Project Documentation & Technical Overview

About the TrafficPulse System

TrafficPulse is an academic mini-project developed by a 2nd-year B.Tech Computer Science & Engineering student. It demonstrates how classical Machine Learning (multinomial Logistic Regression) can model, analyze, and predict urban traffic congestion states using standard transit variables.

Project Background

Objectives & Real-World Motivation

Why urban traffic prediction is critical for sustainable city mobility.

🚦

Proactive Commute Planning

Rather than reacting to bumper-to-bumper delays after getting stuck, traffic classification enables commuters to anticipate bottlenecks based on departure time and corridor characteristics.

📊

Machine Learning Grounding

Demonstrates the real-world application of supervised classification, showing how nominal variables (roads, weekdays) combine with continuous measurements (volume, velocity) to produce actionable decisions.

🌱

Emissions & Idle Reduction

Vehicles crawling in low-gear congestion emit up to 80% more carbon monoxide per kilometer. Predictive routing aids in smoothing transit peaks and lowering fuel burn across urban clusters.

Algorithm & Mathematical Formulation

How the Logistic Regression Classifier Works

Understanding the classification logic, feature normalization, and decision boundaries.

1. Input Representation (18 Dimensions)

Machine learning models cannot directly process textual names like "Airport Road" or "Monday". We convert categorical values into binary indicator columns using One-Hot Encoding:

[Airport_Rd, Phase7_Mkt, Phase3B2, Landran_Rd, Kharar_Hwy, IT_City, Kumbra, PCA_Stadium,
 Mon, Tue, Wed, Thu, Fri, Sat, Sun,
 Hour_of_Day, Vehicle_Count, Avg_Speed_kmh] → Shape: (1, 18)

2. Feature Standardization (StandardScaler)

Vehicle counts range from 10 to 1,200, while speeds range from 5 to 80 km/h. If unscaled, the large magnitude of vehicle counts would overpower the speed and time features during gradient descent. StandardScaler rescales each feature to have a mean of 0 and standard deviation of 1:

z = (x - μ) / σ

3. Multinomial Softmax Classification

For the 3 congestion categories ($k \in \{0, 1, 2\}$), the model calculates a linear score $z_k = \mathbf{w}_k^T \mathbf{x} + b_k$ and transforms it into calibrated probabilities using the Softmax function:

P(y = k | x) = exp(z_k) / Σ exp(z_j)

The predicted category is the one with the maximum probability ($\text{argmax}_k P(y=k|\mathbf{x})$).

⚠️ Academic Prototype & Limitations Notice

Simulated Dataset Notice: TrafficPulse is developed strictly as a 2nd-year B.Tech academic mini-project. The underlying dataset (traffic_data.csv) contains simulated transit records based on mathematical models and capacity guidelines. It does not pull live sensor telemetry or municipal traffic camera feeds.

Evaluation Integrity: High test set accuracy (~94.4%) reflects the model's ability to learn patterns within the synthetic distribution; it should not be represented as verified field performance on actual live traffic.
